1. Quick Revision: Variables

In Scratch you used set [score] to 0. In Python we write score = 0. A variable is a box with a name that keeps something inside. Press ▶ Run, then change the numbers and run again!

2. Meet the Three Data Types

🔢 int
Whole numbers, no dot.
7 100 -3
🌊 float
Numbers with a dot.
2.5 3.14 0.5
🔤 string
Words inside quotes.
"Esse" 'cat'
💡 Trick: 5 is a number, but "5" in quotes is just text, like a letter! Open the 🔤 String tab and try example 10 to see the magic.
